## 📖 About

This repository documents my journey in **VLSI Design** using **Cadence Virtuoso**. It contains CMOS digital circuits designed, simulated, and verified as part of my learning process. Starting with basic logic gates, the repository will gradually expand to include combinational circuits, sequential circuits, layouts, and verification results.

---

## 🎯 Objectives

* Learn CMOS digital circuit design.
* Design and simulate logic gates using Cadence Virtuoso.
* Perform transient and DC analysis.
* Create physical layouts.
* Verify designs using DRC and LVS.
* Build a structured VLSI design portfolio.

---

## 🛠️ Tools & Technologies

* **Cadence Virtuoso**
